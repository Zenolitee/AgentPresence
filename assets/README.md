# Assets

These files are source images for uploading to a Discord Developer Application as Rich Presence art assets. Discord does not read these local files at runtime.

Default asset keys expected by `config.example.json`:

- `codex-logo` from `codex-logo.png`
- `claude-logo` from `claude-logo.png`
- `opencode-logo` from `opencode-logo.png`
- `pi-logo` from `favicon.svg` or `logo.svg`

`favicon.svg` includes a dark rounded-square background and is the better Pi upload source for Discord. `logo.svg` is the transparent white Pi mark. `pi-logo.png` is kept as the older Inflection AI wordmark fallback.
